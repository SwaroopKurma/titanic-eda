# Titanic EDA

Exploratory Data Analysis on the Titanic dataset using Python.

## What this project covers
- Data cleaning with Pandas
- Statistical analysis with groupby
- Data visualization with Matplotlib and Seaborn

## Libraries used
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Charts created
- Survival count bar chart
- Age distribution histogram
- Survival by age overlapping histogram
- Survival by class countplot
- Feature correlation heatmap
- Age per class boxplot
- Age vs Fare scatter plot
- Subplots dashboard
